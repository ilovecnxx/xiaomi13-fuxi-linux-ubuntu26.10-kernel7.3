## 1. shim 退役

**关键发现：回滚镜像 shim7 启动不了现在的默认/回退条目。**
- 【实】`scripts/fuxi-shim/init:124` 只认 `$d/initrd`；`fuxi-kernel-install` 写的是 `initrd.img`。deb3/4/5 条目只有 initrd.img，cmdline 是 root=UUID。
- 【推】shim7 kexec deb4/deb5 时不带 initrd → 内核自己解析不了 root=UUID → panic → ABL 进 Android。
- 【实】能被 shim 启动的只有 deb1、deb2、t281（内建 initramfs）。

最小改动：
1. `fuxi-kernel-install` cmd_add / cmd_initrd 在条目里加 `ln -f initrd.img initrd`（硬链接，不占空间）→ shim7 不用重编就能启动 deb3+【推】；然后对 deb4、deb5 跑 `fuxi-kernel-install initrd <版本>`。
2. 删 `fuxi-kernel-install:119-120`（shim6 以前的老 shim 没有 fuxi.entry 时的猜测），改 :3/:39 注释。
3. 手机：删 `/boot/fuxi/last-shim.log`（37 KB）、`fuxi-kernel-install remove t281`；第 1 步做完后删 deb1；deb2 在那之前留着（shim 能启动的已知好条目）。
4. 删 `work/kbuild/abl-fuxi-shim1..6.*`（24 个文件，65 MB，未跟踪）；留 shim7 的 img/dtb/config/build.json 和 shim-initramfs.list。
   内核树 shim DTS（b5e030ab9）和内建 DTB / 早期控制台（2be6d1f2f）挪到 `fuxi/legacy-shim` 分支，从 consolidate 去掉。
5. 保留：Image.gz 解压（:101-108，shim7 的 `kexec -c` 要用）、tries 文件逻辑、fuxi-boot-ok 的 `rm tries` / `!fuxi.shim`、`scripts/fuxi-shim/` + `fuxi-build-shim.sh`（建议移到 scripts/legacy/）。
