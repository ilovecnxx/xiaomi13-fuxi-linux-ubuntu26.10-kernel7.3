## 5. 已解决的问题
- **ttyGS0 阻塞 role 切换（根因 + 永久修复，均已实测）**
  - 现象：写 `role=host` 返回 0 但无 dmesg、角色不变；drd_work 卡在 `gserial_free_port`（`drivers/usb/gadget/function/u_serial.c`），等 ttyGS0 的所有打开者关闭。
  - 占着 ttyGS0 的是 initramfs 启动的交互 shell（`/bin/sh -i`，setsid 出来的），switch_root 时没被清掉，带进 Ubuntu 成了 PID 277（init.scope）。
  - **真根因（11-06 新发现）**：`/init` 里原来的 `pkill -KILL -f "sh -i"` 从来没生效——这个 busybox **没编 `pkill`/`pgrep`/`ps`**（`strings build/initramfs/bin/busybox` 里一个都没有），执行时静默 "applet not found"。
  - 修法：见第 4 节 `build/initramfs/init`；`/tmp/do_switch` 先立标志挡住 respawn，再按 fd 找 ttyGS0 持有者 kill。
  - 验证（#276 实测）：开机后 `ps` 无 `sh -i`、`/proc/*/fd` 无 ttyGS0、`role` 从 `device` 写 `host` 后立即变 `host`，bus1/bus2 root hub 都在。
- **OTG 主机模式**【已实测】：如上，#274 手动 kill 后 U 盘枚举成功。
