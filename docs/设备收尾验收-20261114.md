## 构建与安装

- 固定 amd64 构建容器补齐 `libc6-dev-arm64-cross`。此前 hexagonrpc 交叉编译缺 ARM64 libc 头文件；
  修复后编译和 C 回归通过。环境包版本保存在镜像及本地构建产物的 lock 文件。
- hexagonrpc、ModemManager 和 81voltd 固定源码重建校验通过。Ubuntu 上游下载失败的 ModemManager
  归档由 HTTPS 镜像补入缓存，仍通过配方固定 SHA256；未降低 TLS 或哈希校验。
- modem 二进制复用恢复集合中产物，其源码记录与当前配方完全一致，SHA256 及依赖检查通过；
  本轮没有将它们安装到手机。
- 手机 dpkg 规则过滤 `/usr/share/doc/*`，导致首次候选安装后丢失 hexagonrpc 来源记录和许可证。
  改为 `/usr/share/fuxi-device/hexagonrpc/` 后重新构建唯一版本 `.1701`，安装后文件保留且 `dpkg -V` 无输出。
- 安装 `fuxi-device_0.20261114.1701_arm64.deb`，SHA256：
  `f21a236102a17a9ae86282ad2562bfc146f80ba0d48ac822539c94e1ae1fb63a`。
  desktop、modem、firmware 包维持原版本。

安装前备份了 deb9/deb8 启动目录、extlinux、默认/回退与计数配置、systemd 和 dpkg 记录，
并用 `dpkg-repack 1.55` 生成旧设备包 `.20261110.1200`。这是实机重打包，不是历史原始 deb。
手机 `/var/backups/fuxi-closeout-20261114/` 与主机 `work/device-closeout-20261114/phone-backup/`
保留备份及已核对的 SHA256SUMS。实际回退安装没有执行，不宣称故障回退演练通过。
