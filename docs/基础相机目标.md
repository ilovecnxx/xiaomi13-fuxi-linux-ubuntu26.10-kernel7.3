# 基础相机目标

在小米 13 主线 Linux 上完成 **IMX800 后置主摄**的取景、拍照保存、回看和退出重开。
当前进度、设备版本、暂停状态及下一步只在 [TASKS.md](../TASKS.md) 维护；
[主摄接通计划](主摄接通计划-20261115.md)记录技术入口。

## 范围

复用已有 libcamera 和相机应用，先完成主摄单模式链路。超广角、前摄、长焦、
镜头切换、录像和原厂徕卡算法延期，见[完整功能矩阵](相机功能完成矩阵.md)。
AF/OIS 可后续完善，但必须记录固定焦点下的清晰范围；无法辨认场景时仍须解决对焦。
共享底层修复继续保留，其他传感器的成果不计入主摄验收。

## 最终验收

| 项目 | 完成条件 |
| --- | --- |
| 主摄接通 | 驱动及端点绑定成功，实际 C-PHY 输出完整 RAW，再验证 RGB |
| 启停 | 同进程启停和应用退出重开各连续 20 次，无 MM0/RPMh 超时、持续 D 状态、内核告警或残留采集进程 |
| 取景 | 普通用户从桌面打开，连续取景 10 分钟，至少 1024×768、平均 15 fps，画面持续更新且方向正确 |
| 拍照 | 至少 2048×1536 JPEG，连续保存 30 张，文件唯一、完整可解码，拍照后取景继续 |
| 回看 | 应用或系统图片查看器能打开照片，退出相机后文件仍可访问 |
| 画面 | 日常光照可辨认场景，无冻结、撕裂或持续短横线；检查样张并记录曝光、颜色和低光局限 |
| 错误处理 | 占用、保存失败和正常关闭可退出并恢复操作，无半写文件或永久等待 |
| 集成 | 桌面入口、普通用户权限、可复现源码/依赖/配置/包校验齐全，正常重启后复验取景、拍照及回看 |

这些数量和时长用于最终验收。开发按 [AGENTS.md](../AGENTS.md) 快速迭代：
单次 RAW → 停流 → 再次开启 → RGB → 取景/JPEG → 完整验收。
帧率和循环数记录实际观测；主机测试、命令参数或独立 EGL 测试不能代替实机结果。
程序超时不保证终止内核 D 状态任务，互连故障后停止追加采集，恢复后再按新假设推进。
