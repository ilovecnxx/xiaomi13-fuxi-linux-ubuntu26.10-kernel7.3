# 完整内核 CI 与构建速度对比

## 实现范围

新增 `.github/workflows/kernel-package.yml`，手动触发完整内核 deb 构建。
复用 `fuxi-build-deb.sh` 和固定 amd64 容器；不复用定向 CI 输出、旧编译目录或 ccache。
产物含内核包、配置、来源与环境记录、完整日志、对应源码和 SHA-256 校验和，Actions 保存 7 天。
候选包未签名、未上机，不自动发布 Release/APT，不改变手机默认/回退内核。

`fuxi-kernel-benchmark.py` 分别记录源码准备、环境准备、编译打包和产物归档秒数。
拒绝未提交的配方、已有输出目录及不足 8 GiB 的可用空间。
`FUXI_BUILD_JOBS` 可指定正整数并行度；普通用户 Podman 使用 keep-id 映射，已实测可写且无需 sudo。
