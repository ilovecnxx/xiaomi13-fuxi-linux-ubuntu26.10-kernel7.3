# 维护补强验收

本轮补强构建、升级恢复、自动检查、维护规则、上游准备和发布流程。
运行基线仍为 `7.4.0-rc1-fuxi-std2`，默认 std2、回退 chg3，另留 deb5。
新增维护设施不表示快充、相机、通话音频或上游提交已经完成。

## 实现与验证

| 范围 | 已实现及验证 | 保留限制 |

## 设备结果

1. 备份旧工具、配置和原 `0.20261107.2200` 安装包后，只安装 `fuxi-device 0.20261108.1`。
2. std2/chg3/deb5 三个条目通过新完整性检查；单元验证和手动健康确认成功。
3. 启动确认服务启用关系从 multi-user.target 迁移到 graphical.target。
4. 对当前 std2 设置 pending=1，使用正常 Linux recovery 重启；自动确认成功，
   `pending=0 tries=0 once=0`，系统无失败单元，默认/回退未改变。
5. 重启后 `fuxi-health.sh --require-wifi --require-sensors` 失败项为 0；
   本次 ADSP/remoteproc 无崩溃，桌面无需重试。

候选内核和新基带二进制保留在主机，未替换设备上已验收的内核/基带。
上述服务和传感器检查不替代实际触摸交互、低电量快充、通话音频和相机验收。
