# 桌面节能与启动验收

2026-11-08，运行内核仍为 `7.4.0-rc1-fuxi-std2`，默认 std2、回退 chg3。
本轮没有更改内核、固件或 Android 分区，没有继续相机和充电实验。

## 实施范围

- `fuxi-uim-provision.py`：只有在每个已插入的受支持 SIM 卡槽都有明确的 GW 预配会话时，跳过原来的 8 秒等待；未知或未就绪状态仍等待并重新查询，未预配 USIM 的激活逻辑保留。不写 NV/EFS。
- `fuxi-desktop-power`：以桌面用户合并 Denial 指定的电源设置，原子替换并保留一次原始备份。实机关闭自动密码锁屏、设置空闲 120 秒熄屏；没有删除系统登录密码。
- `fuxi-auto-brightness`：通过 SensorProxy 领取环境光传感器，采用有界亮度曲线、滞回与逐秒变化限制；检测到手动改亮度后让出 60 秒。熄屏时释放传感器并停止写亮度，不因环境光变化主动亮屏。
- 亮度服务仅绑定 Denial，默认不由包安装启用，本机已显式启用。空闲自动挂起仍关闭，避免把尚未验收的 WiFi 唤醒问题带入日常使用。
- 打包阶段移除 modem/desktop 暂存目录中的 Python 缓存，不将测试导入产生的缓存装入设备。

## 启用与回退

在设备上以 root 管理服务：

```bash
systemctl enable --now fuxi-auto-brightness.service
systemctl restart fuxi-auto-brightness.service
# 回退为手动亮度
systemctl disable --now fuxi-auto-brightness.service
```

以桌面用户执行设置工具；Denial 会读取设置变化，不需要远程重启桌面：

```bash
runuser -u fuxi -- /usr/bin/fuxi-desktop-power --lock disabled --idle-seconds 120
# 恢复自动锁屏
runuser -u fuxi -- /usr/bin/fuxi-desktop-power --lock enabled
```

首次修改前的设置保存在桌面用户配置目录的 `denial/settings.before-fuxi-power.json`（通常在 `/home/fuxi/.config/`）。
整体恢复备份会覆盖之后的其他设置修改，通常优先使用上述显式恢复命令。
确需整体恢复时，以该桌面用户将备份复制为同目录临时文件，权限设为 0600，再用 `mv` 替换 `settings.json`；先保留当前设置副本。

本轮只完成上述改动和验证。原厂功能缺口、NFC、GNSS、其他传感器及虚拟化/TUN 状态见 [`功能覆盖核查`](功能覆盖核查-20261108.md)。
