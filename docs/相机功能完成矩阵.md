# 相机功能完成矩阵

更新：2026-11-14。目标覆盖四颗传感器和用户可用的完整相机流程。
单个传感器出图、软件 ISP 单项修复或成功编译都不能视为全部相机功能完成。

| 功能 | 当前证据 | 剩余工作与验收条件 |
|---|---|---|
| OV13B10 超广角 | RAW/RGB 已出图；CPU 首帧、独立进程反复采集通过 | 修复短横线，检查曝光/颜色/裁切、所有模式及长时稳定性 |
| IMX800 主摄 | 已知地址芯片 ID 0x0800 已重复读到；本地保留小米模式数据 | 本机电源/时钟/CSI 配置、V4L2 驱动、RAW/RGB 和控制实测 |
| OV32C 前摄 | 模块和接线资料已定位；历史 ID 读取为 0 | 确认身份/上电，再实现驱动、自拍方向及预览/拍照/录像 |
| S5K3K1 长焦 | 首次 ID 0x30b1，后续 CCI 超时 | 修复上电/CCI 稳定性，驱动及多模式采集 |
| 软件 ISP 首帧 | 原生构建、GDB A/B、六轮 CPU 2,520 帧通过 | 仍是隔离候选；系统包集成与桌面回归 |
| GPU 缓冲和图像回收 | 已确认逐帧 EGL image 泄漏；新补丁有资源计数与错误注入工具 | 详见 GPU 验收；同进程 start/stop、context 释放仍待完成 |
| CAMSS/互连 | HF 时钟候选允许多轮采集 | MM0/RPMh 根因、匹配投票条件的复测、系统挂起恢复 |
| 取景/切换镜头 | cam 命令行可采集超广角 | PipeWire/portal/桌面应用稳定取景，四镜头切换与退出重开 |
| 照片 | 实验 RGB/RAW 帧 | 可用 JPEG、保存与回看、方向/元数据/失败提示；各镜头实测 |
| 录像 | 尚无完整端到端验收 | 编码、音画同步、保存播放、长录/取消/磁盘不足行为 |
| 控制与画质 | 软件 ISP 基础算法可运行，未标定 | AE/AWB、手动曝光/增益、帧率、裁切/缩放、颜色与低光质量 |
| AF/OIS | AK7314 与 BU24xxx 线索存在 | 驱动、标定与闭环控制；适用主摄/长焦实测，不盲写执行器 |
| 闪光灯 | 未验收相机流程 | 手电/拍照闪光同步及热限制 |
| 安装/权限 | 实验采集以普通 fuxi 用户运行 | 可复现软件包、权限隔离、升级回退、桌面应用完整验收 |

## 主摄资料

发现 GPL-2.0-only 参考项目
[fp5-imx800](https://github.com/isyourbrainfoss/fp5-imx800/tree/c2817a89722ee9d9378843368b13f8532244a72f)。
参考设备使用 24 MHz、地址 0x1a；本机历史测得 19.2 MHz、地址 0x10。
参考驱动曝光/增益尚有占位实现，不能直接当作本机可用驱动。

原恢复集合保存了本机两种 IMX800、OV32C 和两种 S5K3K1 模块二进制。
只读试跑参考模式解析器可找到小米 IMX800 的 8192x6144、4096x3072、
1920x1080 等寄存器表，但固定偏移的身份字段明显不符已知 ID；参考项目的
init/stream/mode 索引也不适用于小米数据。当前只用于定位，未生成部署用表、
未写传感器，也未公开原厂二进制。下一步必须验证二进制结构、寄存器宽度/延时、
模式元数据和本机时钟，不使用参考脚本的估算 pixel rate。
