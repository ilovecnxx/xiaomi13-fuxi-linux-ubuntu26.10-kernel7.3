# 相机功能完成矩阵

更新：2026-11-15（Asia/Tokyo）。**当前仅推进 IMX800 主摄基础流程**，见
[基础目标](基础相机目标.md)及[主摄接通计划](主摄接通计划-20261115.md)。超广角、
前摄、长焦、镜头切换、录像及徕卡体验延期。下表保留完整功能清单，不代表并行开发范围；
原厂组件依赖见[移植评估](小米徕卡相机移植评估-20261114.md)。
单个传感器出图、软件 ISP 单项修复或成功编译都不能视为全部相机功能完成。

## 主摄资料

发现 GPL-2.0-only 参考项目
[fp5-imx800](https://github.com/isyourbrainfoss/fp5-imx800/tree/c2817a89722ee9d9378843368b13f8532244a72f)。
参考设备使用 24 MHz、地址 0x1a；本机历史测得 19.2 MHz、地址 0x10。
参考驱动曝光/增益尚有占位实现，不能直接当作本机可用驱动。

原恢复集合保存了本机两种 IMX800、OV32C 和两种 S5K3K1 模块二进制。
只读试跑参考模式解析器可找到小米 IMX800 的 8192x6144、4096x3072、
1920x1080 等寄存器表，但固定偏移的身份字段明显不符已知 ID；参考项目的
init/stream/mode 索引也不适用于小米数据。当前只用于定位，未生成部署用表、
未写传感器，也未公开原厂二进制。后续新增[结构化只读解析](相机模块解析-20261114.md)，
六份本地模块与 12 项合成测试通过，已区分真实寄存器宽度、延时、引用和表角色。
仍须验证未解码字段、checksum、模式语义和本机时钟，不使用参考脚本的估算 pixel rate。
后续[单模式核对](主摄单模式核对-20261115.md)确认两份模块的 init/mode1/启停表、
身份、电源和单模式元数据一致；基于 PLL 得到 link frequency 1.4496 GHz 候选，
仍未通过实机验证。启流包含双向翻转，且模式含 DT 0x30 辅助流，待接收端和驱动共同核实。
