# 快充修复进展（2026-11-07 晚）

## 当前结果

**电池认证链路已打通；快充尚未修好，功率没有提高。**

- `chg2` 实机两次干净启动后，随机挑战的 HMAC-SHA256 摘要均通过校验，固件 `AUTHENTIC=1`。
- 当前内核 `7.4.0-rc1-fuxi-chg2`，默认 chg2、回退 deb5；`pending=0 tries=0 once=0`。
- 充电器 UVDM 认证未完成。尝试 Type-C host 数据角色时超时，此后协商退到 `USB_FLOAT`（XM real_type 131），约 5.02 V / 0.922 A。
- UCSI soft reset、PD hard reset 均未恢复 PD，需要用户重新插拔充电器后再测。
- 未伪造充电器认证结果，未提高输入电流上限、未修改电压/温控策略。
- Android/固件分区及 recovery_b 未写入；仅更新 Linux 分区内的内核包和设备支持文件。

## 实现

内核隔离工作树 `~/.cache/fuxi-charge74`，分支 `fuxi/charge-7.4`，
基于收敛树 `a5dcbb9cc`，提交 `89846aa3d`。仅改 `drivers/power/supply/qcom_battmgr.c`。
相机和语音工作树没有混入本次构建。

- 新增 fuxi 专用 `xiaomi/` 属性组；认证写接口权限 0600。
- 支持 52 字节电池摘要请求和 32 字节 UVDM 多字请求。
- 保持 GLINK 请求互斥，匹配 GET opcode/属性号，检查 12/20/40 字节响应与错误码。
- 当前官方模块的 SET ACK 不保证回显属性，因此只按 SET opcode 和长度匹配；其余 GET 仍按属性匹配。
- 属性编号采用当前 309 固件对应值；未直接照搬旧版 `fuxi-t-oss` 枚举。

补丁：`work/patches/charging-auth-20261107/0001-fuxi-battery-mipps-auth.patch`。

设备包新增 `fuxi-mipps-auth`、systemd 服务和 udev 插拔触发。协议及公开密钥候选来自
Armbian `c95374efd50807424c906e885d3b2c0452c27ba4`，GPL-2.0-only，包内附来源与许可证说明。

本机只有一个电量计，跳过 sheng 的 slave 电量计步骤。程序只在摘要通过后写 `authentic=1`；
保留已认证状态，等待异步摘要更新，并检查插拔变化。测试发现反复重新挑战不能稳定完成，
因此不能为了复测而无条件重新验证已经认证的电量计。

自动服务固定使用 `--battery-only`；Type-C 角色切换仅在显式 `--swap-data-role` 时执行，
不作为日常默认行为。UVDM 认证尚未验收，不能据此宣称支持 MiPPS 或 67 W。

## 构建与验证

```sh
FUXI_KTREE=~/.cache/fuxi-charge74 FUXI_KOUT=~/.cache/fuxi-charge74-out scripts/fuxi-build-deb.sh chg2
make -C ~/.cache/fuxi-charge74 O=~/.cache/fuxi-charge74-out ARCH=arm64 CROSS_COMPILE=aarch64-linux-gnu- LOCALVERSION=-fuxi-chg2 W=1 drivers/power/supply/qcom_battmgr.o
python3 -m unittest discover -s scripts/tests -v
```

- chg2 完整内核包及充电驱动 `W=1` 编译通过。
- 主机回归 65 项全部通过，含摘要重放/失败、延迟响应、已认证复用、拔线保护与充电器失败上报。
- chg1 的认证响应接入了错误回调分支，实测超时，已由 chg2 修正；不要把 chg1 设为回退。
- chg2 deb SHA256：`c0883596fa9ca4eb3676e48225ab2a52e68a6d109a0ac35cda25fe286968b45f`。
- 设备包版本：`0.20261107.2005`；仅部署 fuxi-device，未升级桌面、基带或固件包。打包时统一剔除主机测试生成的 `__pycache__`。
- 设备包 SHA256：`2e608c8e57a43953546aadcc0f14ee49edd2ee53d97cb266531f0f1d8e18ffdb`，设备端安装前校验一致。
- 末次采样输入 5.018 V / 0.922 A（约 4.63 W），电池 56%、净电流 +740 mA、25.9 摄氏度；`AUTHENTIC=1`、`pd_verifed=0`、`fastchg_mode=0`，不能判定为快充。
- 现场 denial、ModemManager、81voltd active，无 failed unit。双卡 IMS 本次未单独复验。

## 继续验证

先重新插拔同一墙充，恢复 PD 检测，再通过 WiFi SSH 采样。
需要同时核对 `real_type`、`PDO2`、`AUTHENTIC`、`pd_verifed`、输入电压/电流、电池净电流和温度。
原先 PDO2 为 `0x2d12c`，按固定 PDO 格式表示 9 V / 3 A；该值不是已协商到 9 V 的证据。

当前仍需区分通用 PD/PPS 兼容策略与小米 MiPPS 认证，不能把固定写认证标志当作认证通过。
如需回退：`fuxi-kernel-install set-default 7.4.0-rc1-fuxi-deb5`，下次仍通过 recovery 重启路径进入 Linux。
