## 5. 已解决的问题
- 按音量下进不了 U-Boot 菜单 → 根因：按早被 ABL 截获进 fastboot，按晚 bootdelay=0 已启动【已证实，用户两次实测】→ 修复：manual-once 一次性开关 → 验证 uboot6/7 实测。
- 手动条目内核 32 s → 根因：root=PARTUUID 时 initramfs-tools wait-for-root 等满 30 s 超时后靠 blkid 回退【已证实：dmesg Run /init 1.37 s，sync_state 超时 31.7 s；改 UUID 后 1.87 s】→ uboot7。
- 用户报启动红字 → 都是每次启动都有的内核 err（arm-smmu fault、geni -517、pmic-glink device link），两次启动 err 均 65 条【已证实】。
- 新版 fuxi-device 不会自动迁移 /etc 旧单元（postinst 迁移只在首次安装 `$2` 为空时跑）→ 手工 mv 到 /var/backups/fuxi-device-migrate/etc/systemd/system/。

## 6. 已尝试且失败的方案
