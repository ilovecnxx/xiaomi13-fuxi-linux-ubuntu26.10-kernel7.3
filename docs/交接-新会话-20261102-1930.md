## 7. 仍存在的问题

1. **【已证实，严重】start(TX) 始终返回 DSP status 1**：每次通话 Android 在 TX OPEN 后、PREPARE/START 前都发一条 `0x01001008`（SET_CAL）校准块；我们没有发。voice_replay 证明空块/重建块被 DSP 以 status 1 拒绝。唯一解锁路径：重新用 `fuxi-gpr-shmdump` 抓全长载荷拿到真实内容。
2. **【已证实，中】RX MFC miid 可能有误**：设计文档 §7s 写"0x448d/0x41c5"，但 shmdump2 分析显示第一次通话目标是 `0x465b`（单声道听筒路径），第二次才是 `0x448d`（双声道扬声器）；0x41c5 在 shmdump2 中不存在。bit5 发到了错误 miid，但 DSP 接受（ret=0）。不是当前卡点，先解决 TX START 再处理。
3. **【推测，低】PATH_CFG 的 3 个 kv pairs 内容未验证**：我们用了猜测值，抓包里只有前 40 字节可见。目前 PATH 通过，暂不阻塞。
4. **git commit 与上游 #1110 留言**：未处理，不在设备测试授权范围内。
