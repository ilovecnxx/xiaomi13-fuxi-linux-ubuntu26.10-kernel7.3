## 5. 已解决的问题
- **哪条 VCPM 命令失败**：回调只打 opcode → 加步骤名 → 是 VSID（`work/claude-logs/voice-graphopen-20261101/test-stepinfo.txt`）。
- **0x01001008 是什么**：头文件无定义 → 共享内存读出 → 一个带外 SET_CFG `{miid 4, param 0x08001163, size, err}`，内容是按 SG 组装的语音校准；ACDB 里搜不到整块，同 SG 记录长度也不同（#111：2984 B 对 1900 B）【已实测】（设计文档 §7e）。
- **外部读 dmabuf**：`process_vm_readv` 返回 -1，`/proc/pid/mem` 返回 -5 → 用 `pidfd_getfd` 复制目标进程的 fd 再 mmap → 读出 32768 B（`work/claude-logs/android-voice-shmdump2-20261102/packets.log` 的 `read=` 字段）。
- **Android GRAPH_OPEN 与我们的图差异**：工具 `fuxi-graphopen-parse.py` 解析 #102/#136 的块（0x2012/0x2013）。TX 完全一致；RX 不同（Android 听筒、我们扬声器）；Android 多发 VCPM 注册与控制链路，ACDB 原样有【已实测】（设计文档 §7g）。
- **刷测忘带序列号**：脚本默认带 `ANDROID_SERIAL`，提交 250d153（只做了 `bash -n`，后续两次真实刷测都正常）。
