## 5. 已解决的问题
- **VSID 被拒范围缩小**：只有 TX/RX 都用我们的图时被拒；单独 TX 或单独 RX 均通过【已实测，#235/#236】（§7l/§7m/§7o）。
- **"跨图连线导致 VSID" 候选排除**：Android 块里没有 TX↔RX 连线；去连线/保留连线两种模式均通过【已实测】（§7m）。
- **TX 端点配置不是 start(TX) 卡点**：SET_CFG 返回 0 但 START 仍 status 1【已实测，#237】（§7p）。
- **离线确认 Android start 顺序**：所有成功 START 均 RX 先于 TX；抓包中所有失败均与先 TX start 或 TX 单独 start 有关【已证实于 packets.log，#170/#610 通过；#232/#235/#237 失败】。
