# CSID 路径复位（2026-11-15）

从 cam10stop 的最新源码继续，保留 CPAS 共享时钟持有、失败锁定和 CSID
停止回调修复。cam10stop 的 RGB 停止超时证据不变，不把软件回调修复等同硬件排空。

## 硬件流程依据

MiCode camera-kernel `fuxi-t-oss` 提交
`6c6099a85cb3154fc8a744c17b6b9f5fd361dea8` 的 VFE top ver4 明确不支持独立
reset，Titan780 的 VFE reset IRQ mask 为零。CSID ver2 stop 则先发立即 PATH
硬件复位，等待复位完成中断，再清理 path/RX IRQ。

候选在公共 CSID stop 加可选的有返回值回调，gen3 执行 config=1、command=1
路径复位并等待现有完成中断；启动保留 config=0x11、command=5。等待前重新初始化
completion，500 ms 未收到中断返回 -EIO。其他代际未设置新回调，保留已有行为。
这不是通过降低 CPAS 检查标准来避免超时。
