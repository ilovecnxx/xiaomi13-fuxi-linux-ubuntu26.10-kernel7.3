## 5. 已解决的问题
- 写 SIM2 被内核自己拒绝（kctl1，28 ms，无 dmesg）→ 根因：`q6apm-voice.c` 的 `op > AR_MAX_MOD_LINKS` 检查，生成表里 `0x7001011` 有 29（TX miid 0x4167）/21（RX miid 0x418e）个输出口 → 修复：`audioreach.c:469` 循环加上限、删检查 → 验证：kctl2 上 dmesg 出现 ADSP 回包（`test2.txt`）。
- 控件挂错组件的风险 → `q6apm_audio_component` 注册在 GPR 设备本身，`dev->parent` 不是 q6apm → 挂到 q6apm-dai（`q6apm.c:888,894`）→ 验证：控件出现且 start 能走到 ADSP。
- 内建模块参数只能走 cmdline（烧在 DTB）→ 改 0644 → 验证：`/sys/module/snd_q6apm/parameters/voice_experimental` 为 `-rw-r--r--`（`test1.txt`）。
- 1929 交接 §6「抓包里没有 0x08001063」**是错的** → 根因：当时对 strace 文本 grep 十六进制串，字节是转义的 → 用 `fuxi-gpr-decode.py` 的 parse 重新解码 → 0x43af INTF_CFG = `{1,4,0xa}`、0x43ad = `{1,4,0x8}`（`android-voice-sequence.txt` #208、#936）。
