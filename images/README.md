# Historical Images

This directory describes the old ABL image layout, not today's boot baseline.
Current state is in [TASKS.md](../TASKS.md); use the
[kernel operation guide](../docs/内核维护与独立升级.md) for normal upgrades.

Generated images are not tracked. Verify each recovered or new artifact against
its own build manifest and checksums. The stale repository-wide `SHA256SUMS`
was removed; old release manifests remain available through Git history.
